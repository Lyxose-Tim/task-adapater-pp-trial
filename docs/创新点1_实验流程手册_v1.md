## 一、阶段 A：实现与单元测试（M7 前半）

### 1.1 新增模块 `ot_align.py`（新文件，接口规格）

| 函数 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `build_D(T, K)` | 帧数 T（Option A 为 7，B 为 8）、阶段数 K | [T,K] | D(i,s)=((i/(T−1)) − (s/(K−1)))²，K=1 时全零 |
| `sinkhorn_log(Ct, a, b, eps, rho, iters)` | 批量代价 [...,T,K]、边际 a[T]、b[K]、ε、ρ（None=平衡）、迭代数 | π [...,T,K]、残差标量 | log 域、单侧不平衡，见 §1.2 |
| `ot_stage_scores(F, T, eps, lam, rho, iters, weight)` | F [NQ,T,d]、T_c [C,K,d]（均 L2 归一化、fp32） | S [NQ,C]、π [NQ,C,T,K]、m [NQ,C,K] | weight ∈ {mass, uniform} |

全模块 fp32；调用侧入口 `.float()`、出口 `.half()`。

### 1.2 log 域 Sinkhorn 更新（单侧不平衡）

```
K̃ = −C̃/ε ;  τ = ρ/(ρ+ε)      # 平衡档（rho=None）取 τ=1
重复 iters 次：
  u ← log a − LSE_s( K̃ + v[None,:] )          # 帧侧硬约束
  v ← τ · ( log b − LSE_i( K̃ + u[:,None] ) )  # 阶段侧软约束
π = exp( K̃ + u[:,None] + v[None,:] )
残差 = ‖π·1 − a‖₁（写入日志，用于判断 iters 是否够）
```

起始 `iters=30`；若残差长期不低于阈值再加。自动微分直接穿过迭代展开，不做隐函数微分。

## 二、阶段 B：坐标式调参（M7 后半 – M8）

**单元定义**：一个配置 = 一次完整训练（沿用 B0 训练日程）+ 开发规模配对评测（600–2500 episode，与 B0 同一 episode 流）+ 3a 诊断（OS）。配置命名 `I1-A-eps{e}` / `I1-B-lam{l}` / `I1-C-rho{r}`。

- **步 A（平衡 OT）**：λ=0、ρ=None，扫 ε。起始对数网格 {0.01, 0.05, 0.1, 0.5}（相对代价尺度 C∈[0,2]，以实验为准）。记录：Acc、OS（**应≈0**，作为命题实证）、π 平均熵、收敛残差。ε 过大时 π 趋于均匀——用 π 熵监控，熵接近上限的配置直接淘汰。
- **步 B（顺序先验）**：固定 ε_A*，扫 λ。起始网格取使 λ·max(D) 与代价尺度可比的量级，如 {0.1, 0.3, 1, 3}。产出 **λ-Acc 与 λ-OS 双曲线**（论文核心图）。预期 OS 随 λ 单调上升；Acc 是否有内点最优是本步的核心问题。
- **步 C（不平衡）**：固定 ε、λ*，扫 ρ。起始 {0.1, 1, 10} 与 None 对照；每个 ρ 同时跑阶段 D 的三种截断评测（ρ 的收益预期主要落在截断测试上，需实验确认）。
- **复核**：最优点邻域做一次 λ×ρ 的 2×2 微网格。
- **种子**：主线最优配置追加 1 个训练种子复跑，估计训练方差。

## 四、阶段 D：时序鲁棒性协议

- **实现点**：`dataset.py` `SubVideoDataset.__getitem__` 的 `frame_id` 计算（L78–87）。做诊断式包装：增加可选采样区间 [lo, hi]，`tick` 改在 [lo·num_frames, hi·num_frames] 内计算；**训练路径不改**，仅评测时启用。
- **三变体**：掐头 [0.25, 1]、去尾 [0, 0.75]、收缩 [0.125, 0.875]。B0 与各 OT 档在同一 episode 集上评测，指标 ΔAcc（相对各自正常采样）。
- **边界处理**：`num_frames·(hi−lo) < 8` 的视频会重复采样，记录其占比；若占比高，报告时分层给出。
- **预期与解读**：不平衡档退化最小为预期结果（需实验确认）；若固定窗口反而更稳，说明截断对阶段-窗口耦合的破坏不如预想，回到 §1.2 的轴上重新解释。

## 七、风险与应对

- **OT 各档全面不敌 B0**：先看 λ 大端能否逼近 B0（U2 形态 + 步 B 曲线右端）；逼近不了优先怀疑实现（D 矩阵朝向、fp32 岛、边际方向）而非思路。
- **步 A 的 OS 不为零**：直接违反 U1——回到单测；若 U1 通过而训练后 OS≠0，检查评测脚本的排列是否施加在 `enh_embedding` 之前。
- **ε 与 λ 尺度耦合**：λ·D 与 C 同量级才有意义；步 B 网格若单调无内点，扩展一档再判断。
- **Sinkhorn 不收敛**：残差监控；先加 iters，再查 ε 是否过小（数值下溢在 log 域已规避，但 ε→0 仍会拖慢收敛）。
